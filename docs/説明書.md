# Soki Editor 取扱説明書

## 1. 概要

**Soki Editor** は、大規模言語モデル（LLM）を活用して学術論文・記事・報告書などの長文ドキュメントを構造的に作成・管理するためのアプリケーションです。

### 主な特長

| 機能 | 説明 |
|------|------|
| プロジェクト管理 | 複数のドキュメントをプロジェクト単位で管理 |
| ルールベース執筆 | 表現ガイドラインをLLMに適用して一貫した文体を維持 |
| ソース管理 | 参照資料をアップロードし、LLMが参照して執筆 |
| 参考文献管理 | ソースに文献情報を付与し、参考文献リストへの掲載可否を設定 |
| マテリアル管理 | 図・表ファイルを管理し、本文への挿入を支援 |
| 文書構造管理 | 章・節・小節の階層構造をアウトラインで管理 |
| チャット生成 | チャット形式でLLMにセクションの生成・修正を指示 |
| 文書レビュー | LLMが全セクションをレビューし、改善コメントをセクションごとに提示 |
| エクスポート | Markdown形式でドキュメント全体を書き出し |

---

## 2. 画面構成

画面最左端の**サイドバー**にあるアイコンで各機能画面に切り替えます。

```
[ Edit ]     ← エディタ（本文執筆・アウトライン管理）
[ Source ]   ← ソース・参考文献管理
[ Material ] ← 図表（マテリアル）管理
[ Rule ]     ← 執筆ルール管理
[ Review ]   ← 文書レビュー
     ：
[ ⚙ ]      ← 設定
```

| アイコン | 機能 |
|---------|------|
| Edit | アウトラインの管理と本文の執筆・LLM生成 |
| Source | 参照資料のアップロードと参考文献情報の管理 |
| Material | 図・表ファイルの管理 |
| Rule | 執筆ルール（ガイドライン）の管理 |
| Review | 文書全体のLLMレビュー |
| ⚙ | LLM API設定などの設定 |

画面左上の **←** ボタンでプロジェクト選択画面に戻ります。
画面上部にはプロジェクト名と、現在のタブに応じた操作ボタンが表示されます。

各タブは左パネル（一覧）と右メインエリア（詳細）の2ペイン構成です。Edit・Review タブは下部にチャット入力バーが表示されます。

## 3. プロジェクト管理

### 3.1 新規プロジェクト作成

1. **←** ボタンでプロジェクト選択画面を開く
2. 「新規作成」ボタンをクリックして、モーダル画面でプロジェクト名を入力
3. 作成後、**⚙ 設定** で以下を設定してください。
    - [必須] OpenAiのAPIキー
    - [必須] 使用するLLMのモデル名
    - [任意] エンドポイントURL
    - [任意] ソース情報で使用するファイルを格納するディレクトリのパス
    - [任意] 図表ファイルを格納するディレクトリのパス

### 3.2 プロジェクトの読み込み

1. プロジェクト選択画面を開く
2. 「プロジェクトを開く」ボタンをクリック
3. プロジェクトファイル(.json)を開く

### 3.3 プロジェクトの保存

バックグラウンドで自動保存されます。

### 3.4 プロジェクトの削除

プロジェクトファイルとデータをエクスプローラー等で手動削除してください。
> **注意**: 削除したプロジェクトは復元できません。
---

## 4. 設定（LLM API）

サイドバー下部の **⚙** アイコンから設定画面を開きます。このプロジェクトで使用するLLMのAPI情報を設定します。

| 項目 | 説明 | 例 |
|------|------|-----|
| APIキー | OpenAIまたは互換サービスのAPIキー | `sk-...` |
| エンドポイントURL | APIのURL（省略可） | OpenAI以外を使う場合に設定 |
| モデル名 | 使用するモデル | `gpt-4o` など |

設定はプロジェクトごとに保存されます。

**対応サービス例**

- OpenAI（デフォルト）
- Azure OpenAI Service
- ローカルLLM（Ollama等のOpenAI互換API）

---

## 5. ルール管理（Rule）

**Rule** タブでは、LLMが文章を生成・チェックする際に従う執筆ガイドラインを設定します。有効化されたルールはすべてのLLM呼び出しに自動的に組み込まれます。

### 5.1 画面レイアウト

```
┌─────────────────┬───────────────────────────────────────────────┐
│   Rules パネル   │           カテゴリ・ルール一覧                  │
│  [新規追加]      │                                               │
│                 │  ∨ 表現方法                        [⚙] [×]   │
│  ∨ 表現         │    ●─ ルール内容...                      [×]  │
│    › ルール1... │    ●─ ルール内容...                      [×]  │
│    › ルール2... │    ●─ ルール内容...                      [×]  │
│    › ルール3... │                                               │
│  ∨ 心構え       │  ∨ 心構え                          [⚙] [×]   │
│    › ルール1... │    ●─ ルール内容...                      [×]  │
│    › ...       │    ...                                        │
│  ∨ その他       │                                               │
│    › ルール1... │  ∨ その他                          [⚙] [×]   │
│                 │    ●─ ルール内容...                      [×]  │
└─────────────────┴───────────────────────────────────────────────┘
```

左パネルにカテゴリとルールのツリーが表示されます。右メインエリアにはカテゴリごとのルールカードが並びます。

### 5.2 ルールのカテゴリ

| カテゴリ | 用途の例 |
|---------|---------|
| 表現方法 | 「句読点は「、」「。」を使う」「受動態を多用しない」など文体に関するルール |
| 心構え | 「専門用語は初出時に説明する」「主張に根拠を必ず示す」など論理・姿勢に関するルール |
| その他 | カテゴリに当てはまらない制約・注意事項 |

### 5.3 ルールの追加

1. 左パネル上部の「新規追加」ボタンをクリック
2. モーダルウィンドウでカテゴリを選択し、ルール内容を入力して保存

### 5.4 ルールの有効・無効切り替え

右メインエリアの各ルールカード左端にあるトグルスイッチ（●─）で個別に有効・無効を切り替えます。無効のルールはLLMへ送信されません。

### 5.5 ルールの編集・削除
- 編集・削除したいルールアイテムをクリックすると選択され、編集モードに移動します。
- ルール内容をテキスト入力で修正できます。
- ルールが属するカテゴリもドロップダウンメニューから変更できます。
- 選択中に表示される **×** ボタンで削除できます。
- ルールアイテム外をクリックすると選択解除されます。


### 5.6 カテゴリの編集・削除

各カテゴリブロック右上の **⚙**（カテゴリ名を編集）/ **×**（カテゴリごと削除）ボタンから操作します。

### 5.7 カテゴリの追加

画面右上の **「セクション追加」** ボタンで新しいルールカテゴリを追加します。

### 5.8 CSVインポート・エクスポート

複数プロジェクト間でルールを共有する際に便利です。画面右上の **インポート** / **エクスポート** ボタンから操作します。

> CSVの形式: `カテゴリ,ルール内容` の2列

## 6. ソース管理（Source）

**Source** タブでは、LLMが執筆時に参照する資料（ソース）を管理します。各ソースには参考文献情報を付与でき、参考文献リストへの掲載可否も設定できます。

### 6.1 画面レイアウト

```
┌─────────────────┬───────────────────────────────────────────────┐
│  Sources パネル  │           ソース詳細                           │
│  [新規追加]      │                                               │
│                 │  ファイル名  [編集アイコン]                      │
│  ▶ ソース1      │                                               │
│    ソース2      │  ∨ 設定                                       │
│    ソース3      │    ID: ref-123                      [削除]     │
│    ...         │                                               │
│                 │  ∨ 文献情報                                    │
│                 │    種類: [論文 ▼]  参考文献リストに掲載 [●─]    │
│                 │    タイトル / 著者 / 掲載誌                    │
│                 │    巻数 / 号数 / ページ / 出版年 / その他       │
│                 │                                               │
│                 │  ∨ 要約                                       │
│                 │    [テキストエリア]       [ソースから要約生成]   │
│                 │                                               │
│                 │  ∨ 内容                                       │
│                 │    全文: [テキストエリア]                       │
│                 │    ファイルパス: ...                            │
│                 │                    [画像解析] [ファイル読み込み] │
└─────────────────┴───────────────────────────────────────────────┘
```

### 6.2 ソースの追加

1. 左パネル上部の「新規追加」ボタンをクリック
2. ファイルのパスを指定するか「ファイル読み込み」でファイルを選択（PDF・Word・テキスト等）
3. ファイル内容は「内容 > 全文」テキストエリアに読み込まれます

### 6.3 設定（ID と削除）

各ソースには一意のID（例: `ref-123`）が自動で割り当てられます。本文での引用時にこのIDを使用します。**削除** ボタンでソースを削除できます。

### 6.4 文献情報の設定

| 項目 | 説明 |
|------|------|
| 種類 | 文献の種別（論文 / 図書 / 図書の一部 / Web など） |
| 参考文献リストに掲載 | ONにするとエクスポート時の参考文献一覧に出力される |
| タイトル | 文献のタイトル |
| 著者 | 著者名 |
| 掲載誌 | 雑誌名（論文の場合） |
| 巻数・号数・ページ | 掲載情報（論文の場合） |
| 出版年 | 出版・発行年 |
| その他 | 補足情報 |

**文献種別ごとの入力項目**

| 種別 | 主な入力項目 |
|------|------------|
| 論文 | タイトル・著者・掲載誌・巻数・号数・ページ・出版年 |
| 図書 | タイトル・著者・出版社・出版地・発行年 |
| 図書の一部 | 章タイトル・著者・書名・編者・出版社・出版地・発行年 |
| Web | タイトル・著者・サイト名・URL・参照日 |

### 6.5 要約

テキストエリアに手動で要約を入力するか、**「ソースから要約生成」** ボタンでLLMが全文から自動生成します。要約はセクション生成時にLLMへのコンテキストとして渡されます。

### 6.6 内容（全文・ファイル操作）

| ボタン | 動作 |
|--------|------|
| ファイル読み込み | ファイルを読み込み、テキストを「全文」に反映する |
| 画像解析 | Vision APIでPDF等の図表・複雑なレイアウトを解析する |
ファイルは、.txt, .md, .pdf, .csvに対応します。

### 6.7 CSVインポート・エクスポート

画面右上の **インポート** / **エクスポート** ボタンからソース一覧を一括操作できます。

## 7. マテリアル管理（Material）

**Material** タブでは、文書内で使用する図・表のファイルを管理します。

### 7.1 画面レイアウト

```
┌─────────────────┬───────────────────────────────────────────────┐

│                 │    ファイルパス: ...      [ファイル読み込み]      │
```

**ファイル読み込み** ボタンでファイルを読み込むと、紐づける画像ファイルを変更できます。

## 8. エディタ（Edit）

**Edit** タブは、文書のアウトライン（構造）管理と本文の執筆・LLM生成を行う中心的な画面です。

### 8.1 画面レイアウト

```
┌──────────────────────────────────────────────────────────────────────┐
│ ← プロジェクト名                [文献挿入] [図表挿入] [セクション追加] │
├──────────────────┬───────────────────────────────────────────────────┤
│   Outline パネル  │                  ドキュメントビュー                │
│  [新規追加]       │                                                   │
│                  │  ∨ 序論                           ↑ ↓ ⚙ ×        │
│   ▶ 序論         │    [概要テキスト（グレーボックス）]                  │
│   ▶ 現在の状況   │    本文テキスト...                                  │
│   ∨ 課題と困難   │                                                   │
│     ∨ 課題       │  ∨ 現在の状況                     ↑ ↓ ⚙ ×        │
│     ∨ 困難       │    [概要テキスト]                                   │
│   ∨ 解決策と展望 │    本文テキスト...                                  │
│     ∨ 解決策     │                                                   │
│     ∨ 展望       │  ∨ 課題と困難                     ↑ ↓ ⚙ ×        │
│   ▶ 結論         │    ∨ 課題   ↑ ↓ ⚙ ×                              │
│   ≡ 参考文献     │    ∨ 困難   ↑ ↓ ⚙ ×                              │
│                  │    ...                                             │
│                  ├───────────────────────────────────────────────────┤
│                  │  チャット入力 "What would you like to know?"        │
│                  │  ≡ [全セクション(骨子) ▼]  ☑ ソース全文参照   [↑]  │
└──────────────────┴───────────────────────────────────────────────────┘
```

### 8.2 Outline パネル（文書アウトライン）

左パネルには文書の章・節・小節の階層ツリーが表示されます。

- 項目をクリックすると対応するセクションへスクロール
- 「新規追加」ボタンで新しいセクションを追加
- 折りたたみ／展開で構造を確認
- 参考文献セクション（≡）は最下部に固定表示
- ctrl+sで都度手動保存
- ctrl+zでundo, ctrl+shift+zでredoできるとよい

### 8.3 ドキュメントビュー

右メインエリアには文書の全セクションがインラインで表示されます。

**各セクションの構成**

| 要素 | 説明 |
|------|------|
| ∨ / › | クリックでセクション本文を展開／折りたたむ |
| セクションタイトル | 章・節の見出し |
| ↑ ↓ | セクションの表示順を移動 |
| ⚙ | セクション設定（タイトル・概要の編集） |
| × | セクションを削除 |
| グレーボックス | セクション概要（LLMへのコンテキスト用サマリー） |
| 本文テキスト | 執筆内容（Markdown形式で直接編集可能） |

### 8.4 チャットインターフェース

画面下部のチャット入力からLLMに指示を送ります。

**送信オプション**

| 設定 | 説明 |
|------|------|
| ≡ (メニュー) | モーダル画面が開き、チャット履歴の管理、削除を行う。全セクション/特定セクションごとに、最大16個まで、ユーザのプロンプト履歴を残す。 |
| 全セクション(骨子) ▼ | LLMへ送信するコンテキストの範囲を指定（全セクション / 特定セクション） |
| ☑ ソース全文参照 | チェック時はLLMで最大5つまで選定した、関連の強いソース全文を送信、未チェック時は要約のみ送信 |
| ↑（送信ボタン） | 入力した指示をLLMへ送信 |

**指示の例**:

```
序論を約800文字で執筆してください。ソースの内容を中心に、環境問題の現状を簡潔にまとめてください。
```
```
「課題」セクションに3つのサブセクションを作成し、セクション概要も設定して。
```
```
「課題」セクションのトーンを、読者への問いかけを含む形に修正してください。
```

### 8.5 セクションの追加

- 画面右上の **「セクション追加」** ボタン
- アウトラインパネルの **「新規追加」** ボタン

のいずれかで新しいセクションを追加します。

### 8.6 文献・図表の挿入

| ボタン | 動作 |
|--------|------|
| 文献挿入 | Sourceタブのソース一覧から文献を選択して本文に挿入 |
| 図表挿入 | Materialタブのマテリアル一覧から選択して本文に挿入 |

## 9. レビュー（Review）

**Review** タブでは、文書全体をLLMが総合的にレビューし、各セクションに対する改善コメントをセクション横に表示します。

### 9.1 画面レイアウト

```
┌──────────────────────────────────────────────────────────────────────┐
│ ← プロジェクト名                                       [　エクスポート]│
├──────────────────────────────────────────────────────────────────────┤
│  ∨ 序論                                                              │
│  ┌───────────────────────────┐  ┌──────────────────────────────┐    │
│  │ 本文テキスト               │  │ [プロンプトにコピー]  [×]    │    │
│  │ 環境問題はもはや無視...    │  │ レビューコメント1            │    │
│  │                           │  │ （問題点と改善提案）         │    │
│  │                           │  └──────────────────────────────┘    │
│  │                           │  ┌──────────────────────────────┐    │
│  │                           │  │ [プロンプトにコピー]  [×]    │    │
│  │                           │  │ レビューコメント2            │    │
│  └───────────────────────────┘  └──────────────────────────────┘    │
│  ∨ 現在の状況                                                        │
│  ...                                                                 │
├──────────────────────────────────────────────────────────────────────┤
│  ここにレビュー用のシステムプロンプトを入力する...                      │
│  ≡ [全セクション(骨子) ▼]  ☑ ソース全文参照                    [↑]   │
└──────────────────────────────────────────────────────────────────────┘
```

### 9.2 レビューの実行

1. 画面下部のシステムプロンプト入力欄にレビューの観点を入力
2. 送信オプションを設定
3. **↑**（送信ボタン）をクリックしてレビューを実行
4. 各セクション右側にレビューコメントカードが順次表示されます
>レビュー用のシステムプロンプトは自動的に保存されます。

**システムプロンプト例**:
```
学術論文として投稿する前の最終チェックを行ってください。
特に以下の点を確認してください：
- 論文全体を通じた主張の一貫性
- 引用・参照の適切さ
- 結論が序論と対応しているか
```

### 9.3 レビューコメントの操作

| ボタン | 動作 |
|--------|------|
| プロンプトにコピー | コメント内容を **Edit** タブのチャット入力にコピーする |
| × | このコメントカードを閉じる |

**プロンプトにコピー** を使ってレビューで指摘された問題点をそのまま Edit タブへ転記し、LLMに修正を依頼できます。

### 9.4 送信オプション

| 設定 | 説明 |
|------|------|
| ≡ 全セクション(骨子) ▼ | レビューに含めるコンテキストの範囲 |
| ☑ ソース全文参照 | LLMで最大5つまで選定した、関連の強いソース全文をレビュー時の参照に含める |

## 10. エクスポート

### 10.1 Markdownエクスポート

画面右上の **「エクスポート」** ボタンをクリックすると、文書全体をMarkdownファイルとしてダウンロードします。

エクスポート内容：

- 全セクションの本文（構造の階層に従った見出し付き）
- 「参考文献リストに掲載」が有効なソースの参考文献一覧
- 図表番号・参考文献番号に変換済みのテキスト

---

## 11. データの仕組み

### 11.1 LLMへ送信される情報

チャット送信時にLLMへ渡される主な情報：

| 情報 | 内容 |
|------|------|
| 有効なルール | Rule タブで有効化した全ルール |
| ソース（概要 or 全文） | 「ソース全文参照」ONの場合は、事前にLLMの処理で選定した最大5つまでのソース全文、OFFの場合は要約のみ |
| 文書構造（骨子） | 全セクションのタイトルと概要 |
| コンテキスト範囲 | 「全セクション(骨子)」設定に従った範囲の現在の文章 |

### 11.2 参考文献と図表の仕組み

- Source タブで「参考文献リストに掲載」をONにしたソースが参考文献として扱われます
- 各ソースのIDを使って本文内に引用を挿入できます
- エクスポート時に自動的に番号形式に変換されます
- Material タブで管理するマテリアルのIDを使って本文内に挿入記法を記述します
- エクスポート時に自動的に番号形式（図1、表2 等）に変換されます

本文中に、
文献: `[^ref-001]`
図表: `![キャプション](ファイルパス "fig-001")`
とMarkdown記法に合わせた形で入力されます。

これらは、後述のレビューやMarkdownエクスポート時に
文献:`[1]`
図表:`図1 キャプション`
という表記に置き換わります。



### 11.4 プロジェクトファイル構成

```
プロジェクトルート/
├── {プロジェクトID}.json   ← プロジェクトデータ
└── {プロジェクトID}/data/
    ├── sources/             ← ソースファイル
    └── materials/           ← マテリアル（図表）ファイル
```

## 付録：よくある操作の流れ

### 新規文書を作成する場合

```
① プロジェクト選択画面で新規作成
② ⚙ 設定 → LLM API設定
③ Rule → 執筆ガイドライン追加
④ Source → 参照資料の追加・要約生成・文献情報設定
⑤ Material → 使用する図表ファイルの追加
⑥ Edit → Outlineでセクション追加・構造作成
⑦ Edit → チャットで各セクションの生成を指示 → 確認・手動修正
⑧ Review → レビュー実行 → コメントを「プロンプトにコピー」→ Edit で修正
⑨ エクスポート → Markdownファイル取得
```

### 参考文献を追加して本文に引用する場合

```
① Source タブでソースを追加・文献情報を入力
② 「参考文献リストに掲載」をONにする
③ Edit タブで「文献挿入」ボタン → 文献を選択 → 本文に挿入される
④ エクスポート時に自動的に番号に変換される
```

### レビュー結果を修正に活用する場合

```
① Review タブでシステムプロンプトを入力してレビューを実行
② 修正したいコメントカードの「プロンプトにコピー」をクリック
③ Edit タブのチャット入力にコメント内容がコピーされる
④ 追加指示を加えて送信 → LLMが修正案を生成
```
