# Soki Editor

構造化された長文ドキュメントをLLMで支援する執筆アプリケーション。

学術論文・記事・報告書などの長文を、章・節・小節のアウトライン構造で管理しながら、LLMによる生成・修正・レビューをチャット形式で行えます。

## 機能

- **文書構造管理** — 章・節・小節の階層アウトラインを管理し、各セクションに概要（LLMコンテキスト）と本文を保持
- **LLMチャット生成** — セクションごとにLLMへ生成・修正を指示。送信コンテキスト範囲（全体/特定セクション）とソース参照深度（要約/全文）を制御可能
- **ソース・文献管理** — .txt / .md / .pdf / .csv をアップロードしてLLMのコンテキストとして参照。エクスポート時に参考文献番号を自動変換
- **マテリアル管理** — 画像ファイルをプロジェクトに紐付け、本文に挿入。エクスポート時に図番号を自動変換
- **ルールベース執筆** — 表現ガイドラインをルールとして登録し、すべてのLLM呼び出しに自動付加して文体を統一
- **文書レビュー** — LLMが全セクションを総合的にレビューし、セクションごとに改善コメントを提示

## 技術スタック

| レイヤー | 使用技術 |
|----------|----------|
| バックエンド | FastAPI + Uvicorn |
| デスクトップUI | pywebview |   
| LLM連携 | OpenAI互換API（OpenAI / Azure OpenAI / Ollama等） |
| ファイル解析 | MarkItDown / PyMuPDF / Pillow |
| データ保存 | ローカルJSONファイル |

## 動作環境

- Python 3.11 以上 3.13 以下

## インストール

```bash
git clone https://github.com/simasimataiyo/Soki-Editor.git
cd Soki-Editor

python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

pip install -e .
```

## 起動

```bash
python main.py
```

アプリケーションウィンドウが開きます。`pywebview` がインストールされていない場合はブラウザで `http://127.0.0.1:808x/` にアクセスしてください（コンソールに表示されるURLを確認）。

## 開発環境のセットアップ

```bash
pip install -e ".[dev]"
pytest
```

## データ構造

プロジェクトデータはローカルに保存されます。

```
{任意のディレクトリ}/
├── {projectID}.json          # プロジェクト全データ（自動保存）
└── {projectID}/data/
    ├── sources/               # ソースファイル実体
    └── materials/             # 図表ファイル実体
```

## コマンド

チャット入力欄と レビュー指示欄で `/コマンド` 構文が使えます。
コマンドは引数を取らず、詳細な指示はコマンドの後ろにフリーテキストで記述します。

### エディットタブ コマンド

| コマンド | 説明 |
|----------|------|
| `/structure-replace` | 既存の骨子を全削除して骨子を再生成（確認ダイアログあり） |
| `/structure-section` | 選択中のセクション配下のみ骨子を生成・修正。既存セクションの本文は変更しない |
| `/structure-add` | 既存の骨子構造を維持して新規骨子を追加 |
| `/draft` | 選択中のセクションの概要から本文を生成 |
| `/rewrite` | 選択中のセクションの本文を書き直し |
| `/expand` | 本文を加筆。文字数はユーザー指示で指定 |
| `/shorten` | 本文を圧縮。文字数はユーザー指示で指定 |
| `/tone` | 文体を変更。文体の種類はユーザー指示で指定 |
| `/clear` | 新しいスコープを作成して会話をリセット |

コマンドの後ろに追加指示を書けます。例:

```
/structure-replace 第1章と第2章を重点的に詳細化して
/draft 論点Aに重点を置いて記述してください
/expand 既存の文献引用を増やして補強してください
/shorten 300文字程度にまとめてください
/tone カジュアルな口調に変えてください
```

### レビュータブ コマンド

| コマンド | 説明 |
|----------|------|
| `/review-structure` | 文書構造・論理の流れに特化してレビュー |
| `/review-rule` | 執筆ルールへの準拠チェックに特化してレビュー |
| `/review-source` | ソースとの整合性チェックに特化してレビュー |
| `/review` | フォーカスなしで総合的にレビュー |
| `/prompt save [名前]` | レビュー指示欄の現在のテキストを名前付きで保存 |
| `/prompt load [名前]` | 保存済みのプロンプトをレビュー指示欄に読み込む |

コマンドの後ろにレビュー指示を追加できます。例:

```
/review-structure 論理の飛躍がないか確認してください
/review-rule 学術的表現が守られているかチェックしてください
```

### @ 参照

`@` を入力するとオートコンプリートが表示され、プロジェクトのソース・マテリアルを検索して挿入できます。

```
@source:<id>      # 指定ソースの全文をLLMコンテキストに注入
@material:<id>    # 指定マテリアルをLLMコンテキストに注入
```

複数の参照を組み合わせて使えます:

```
@source:ref-001 @source:ref-002 これらのソースを比較して論点を整理してください
```

## 本文中の参照記法

```
文献引用:  [^ref-001]                    → エクスポート時 [1]
図表挿入:  ![キャプション](path "fig-001") → エクスポート時 図1 キャプション
```

## LLM設定

APIキー・エンドポイントURL・モデル名はプロジェクトごとに設定します。OpenAI互換APIであればローカルLLM（Ollama等）も利用できます。
